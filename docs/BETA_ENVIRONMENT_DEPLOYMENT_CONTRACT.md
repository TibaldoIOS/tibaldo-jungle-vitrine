# Jungle BETA deployment contract

The BETA artifact is built with the following explicit deployment values:

- `JUNGLE_ENV=beta`
- `NEXT_PUBLIC_JUNGLE_ENV=beta`
- `NEXT_PUBLIC_JUNGLE_ORIGIN=https://beta-jungle.tibaldo.fr`
- `NEXT_PUBLIC_SHOP_URL=https://beta-shop.tibaldo.fr`

This keeps the global prelaunch curtain inactive, makes BETA non-indexable,
blocks crawling, and keeps the PUBLIC sitemap unavailable.
