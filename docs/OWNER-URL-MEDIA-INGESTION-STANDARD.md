# Standard d’ingestion d’un média fourni par URL par l’Owner

Ce contrat s’applique uniquement lorsqu’une URL précise est fournie par l’Owner et que celui-ci confirme explicitement les droits d’utilisation dans l’écosystème TIBALDO. Il ne s’applique jamais automatiquement à une URL trouvée sur le Web.

`OWNER_URL → téléchargement contrôlé → identité exacte → WebP optimisé → nom SEO lisible → alt naturel → provenance Jungle → projection Caisse/Shop`.

La source est téléchargée une seule fois, validée puis convertie sans transformation morphologique. Le dérivé local TIBALDO est servi sans hotlink. La provenance, la base de droits et les empreintes sont conservées dans le registre. L’identité reste exacte, sans fuzzy matching. La présence d’un média ne modifie jamais le stock ni la publication commerciale.
