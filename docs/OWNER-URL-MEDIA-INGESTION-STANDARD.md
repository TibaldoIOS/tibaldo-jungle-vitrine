# Standard d’ingestion d’un média fourni par URL par l’Owner

Ce contrat s’applique uniquement lorsqu’une URL précise est fournie par l’Owner et que celui-ci confirme explicitement les droits d’utilisation dans l’écosystème TIBALDO. Il ne s’applique jamais automatiquement à une URL trouvée sur le Web.

1. Télécharger la source une seule fois et vérifier le statut HTTP, le type MIME, les dimensions et l’intégrité du fichier.
2. Vérifier l’identité botanique exacte sans correspondance approximative.
3. Conserver dans le registre la source, la date de preuve, la base de droits et l’empreinte de la source.
4. Produire un dérivé WebP contrôlé, sans transformation morphologique, avec un nom de fichier descriptif, stable, ASCII et séparé par des tirets.
5. Rédiger un texte alternatif naturel décrivant uniquement ce qui est réellement visible.
6. Servir le dérivé local TIBALDO, jamais un hotlink tiers.
7. Enregistrer le média dans l’autorité documentaire Jungle, puis laisser les contrats existants le projeter vers Caisse et Shop.
8. Ne jamais déduire la disponibilité, le stock ou la publication commerciale de la présence d’un média documentaire.

Chaîne de référence : `OWNER_URL → téléchargement contrôlé → identité exacte → WebP optimisé → nom SEO lisible → alt naturel → provenance Jungle → projection Caisse/Shop`.
